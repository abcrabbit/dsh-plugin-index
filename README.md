# DSH plugin index

bcrabbit 的 DSH 插件索引。

## 使用

在 DSH 中打开 **设置 → 插件**，在「实验性插件」下启用 **自定义插件索引**，
然后在插件的 **发现** 标签页点击 **添加索引源**，填入：

```
https://raw.githubusercontent.com/abcrabbit/dsh-plugin-index/main/index.json
```

## 插件

- dsh-plugin-screenshot-insert — 截图标注并插入输入框
- dsh-plugin-prompt-enhance — 提示词增强
- dsh-plugin-deepseek-usage — 余额与 Token 用量面板
- dsh-plugin-preview-popout — 预览面板拖出独立窗口
- dsh-plugin-deliverable-menu — 交付物文件悬浮菜单
- dsh-plugin-deliverable-link-route — 交付物链接路由
- dsh-plugin-session-delete-v3 — 删除会话
